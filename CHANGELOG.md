# Changelog

Changes describe source versions; they do not imply a Web Store listing, published package or release tag.

## 0.1.0 — Initial source version

### Added

- Manifest V3 extension with explicit active-tab recording and manual replay.
- Local saved-guide library and temporary recording/replay session storage.
- Bounded version 1 JSON import/export, instruction editing and step removal controls.
- Exact origin/path matching, restricted selectors and target tag/role/name checks.
- Document/token/progress-bound internal messages and serialized state updates.
- On-page highlighting, pause/resume/stop and missing/changed-target feedback.
- Reproducible extension ZIP build, original icons and static installation/practice pages.
- English usage, privacy, architecture, restoration and contribution documentation.

### Boundaries

Automatic clicks, form-value capture, permanent all-site permissions, cloud guide storage, embedded-frame/shadow-root controls and Web Store publication are outside this version.
